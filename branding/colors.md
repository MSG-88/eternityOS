# Eternity 08 palette

| Token       | Hex       | Use |
|-------------|-----------|-----|
| background  | `#070B14` | wallpapers, GRUB, Plymouth, greeter base |
| panel       | `#0D1320` | panels, sidebars, cards |
| accent      | `#19D3F5` | the "08", selections, progress, links |
| accent-dim  | `#0E8FA8` | secondary accent, borders, ring |
| text        | `#E6F1FF` | primary text on dark |
| muted       | `#7C8BA1` | hints, secondary text |

Typography: Inter (UI, wordmark), JetBrains Mono (terminal, code).

Wordmark: "ETERNITY" in Inter Bold, wide letter-spacing, text colour; "08"
in Inter ExtraBold, accent colour, set inside a thin accent-dim ring. The
ring-and-08 alone is the app/system icon.
